--------------------------------------------------------------------------------
DASHBOARD 2: INDIVIDUAL STOCK QUANTITATIVE & TECHNICAL ANALYSIS
--------------------------------------------------------------------------------
Goal: Deep-dive quantitative evaluation of individual S&P 500 stocks.

Inputs & Controls:
- Stock Search Bar / Dynamic Dropdown: Search & select any constituent of S&P 500.
- Timeframe Selector: 1D, 5D, 1M, 1Y (Default 1Y).

Visual Components:
1. Price & Return Performance Chart:
   - Candlestick or line chart displaying price action over selected timeframe along with cumulative Return percentage:
     $$\text{Return (\%)} = \left( \frac{P_{\text{current}} - P_{\text{start}}}{P_{\text{start}}} \right) \times 100$$

2. Return Frequency Histogram & Quantitative Metrics:
   - X-axis: Daily Return Percentage buckets ($+$ and $-$ returns).
   - Y-axis: Frequency count of trading days.
   - Statistical Summary Cards:
     * Expected Mean Daily Return: $\mu = \frac{1}{N} \sum_{t=1}^{N} R_t$
     * Historical Volatility ($\sigma$): Standard Deviation $\sigma = \sqrt{\frac{1}{N-1} \sum_{t=1}^{N} (R_t - \mu)^2}$
     * Win Rate / Positive Return Probability (%): 
       $$P(R > 0) = \left( \frac{\text{Count}(R_t > 0)}{N} \right) \times 100$$

3. Volume Profile & Dynamic Key Levels Side-Panel:
   - Real-time display of current price.
   - Volume Profile calculation metrics:
     * Point of Control (POC): Price level with highest traded volume.
     * Value Area High (VAH): Upper boundary of 70% value volume range.
     * Value Area Low (VAL): Lower boundary of 70% value volume range.

4. GitHub-Style Daily Return Calendar Heatmap:
   - Grid matrix (Months vs Days of Week) modeling daily return intensity.
   - Color grading: Dark green (High positive return) to dark red (High negative return), neutral dark grey for flat days. Placed adjacent to return histogram.

5. Multi-Stock Return Comparison & Correlation Matrix:
   - Multi-select input to add peer comparison stocks.
   - Comparative return overlay chart.
   - Pairwise Pearson Correlation Coefficient matrix table:
     $$\rho_{X,Y} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$$

6. CAPM & Security Market Line (SML) Valuation Zone Chart:
   - Plot Security Market Line (SML) using formula:
     $$E(R_i) = R_f + \beta_i \left( E(R_m) - R_f \right)$$
     (where $R_f$ is US 10Y Treasury yield and $E(R_m)$ is benchmark expected return).
   - Position target stock on graph ($X = \beta_i$, $Y = \text{Actual/Expected Return}$).
   - Dynamic expected target price output based on CAPM expected rate of return.
   - Visual Zone Annotations: Explicitly label plot regions as "Underpriced / Alpha > 0" (above SML) and "Overpriced / Alpha < 0" (below SML).

DASHBOARD 3: FINANCIAL FUNDAMENTALS & MARKET VALUATION
--------------------------------------------------------------------------------
Goal: Fundamental statement analysis and institutional analyst sentiment.

Key Metric Header Cards:
- Current Stock Price, Market Capitalization, P/E Ratio, P/BV Ratio, Trailing EPS, Beta ($\beta$), 6-Month Sharpe Ratio:
  $$SR = \frac{R_p - R_f}{\sigma_p}$$
- CAPM Derived Target Price.

Visual Components:
1. Revenue & Earnings Trend + Estimates:
   - Quarterly Bar/Line chart displaying historical Revenue & Earnings per Share (EPS).
   - Dynamic 1-Quarter Forward Consensus Estimate overlay.
   - Growth indicators badge: QoQ (Quarter-over-Quarter) % and YoY (Year-over-Year) % growth.

2. Interactive Income Statement Sankey Diagram:
   - Flow diagram mapping: Total Revenue $\rightarrow$ Gross Profit & Cost of Goods Sold (COGS) $\rightarrow$ Operating Income & Opex $\rightarrow$ Net Income & Taxes.

3. Profitability & Margin Trend Lines:
   - Multi-line trend chart showing Gross Margin %, Operating Margin %, and Net Profit Margin % across quarterly periods, with QoQ & YoY delta metrics.

4. Comprehensive Financial Statements Data Tables:
   - Tabbed financial views:
     Tab A: Valuation Ratios
     Tab B: Profitability & Income Statement
     Tab C: Balance Sheet & Cash Flow Summary

5. Institutional Analyst Consensus Breakdown:
   - Recommendation breakdown pie/bar graphic (Buy %, Hold %, Sell % proportions).
   - Target price consensus distribution metrics (Lowest target, Mean target, Highest target price across research institutions).

--------------------------------------------------------------------------------
DASHBOARD 4: ASSET ALLOCATION & PORTFOLIO SIMULATOR
--------------------------------------------------------------------------------
Goal: Interactive portfolio construction and benchmark comparison.

Interactive Inputs:
- Stock picker: Select any stocks from the dataset.
- Weight allocation (%): Interactive sliders/inputs to set target portfolio weights ($\sum w_i = 100\%$).

Visual Components:
1. Sector Allocation Donut Chart (Left Side):
   - Aggregated portfolio exposure grouped into the 11 Standard S&P 500 GICS Sectors:
     1. Technology
     2. Financial Services
     3. Industrials
     4. Communication Services
     5. Healthcare
     6. Consumer Cyclical
     7. Energy
     8. Consumer Defensive
     9. Basic Materials
     10. Real Estate
     11. Utilities
   - Hover behavior: Hovering mouse over a sector arc segment expands a dynamic tooltip revealing the individual stock breakdown and weighting inside that specific sector.

2. Portfolio Analytics Performance Card (Right Side):
   - Calculated over a 1-Year historical lookback window:
     * Expected Portfolio Return: $E(R_p) = \sum w_i E(R_i)$
     * Portfolio Volatility ($\sigma_p$): 
       $$\sigma_p = \sqrt{\mathbf{w}^T \mathbf{\Sigma} \mathbf{w}}$$
     * Portfolio Sharpe Ratio ($SR_p$)
     * Portfolio Beta relative to S&P 500 Benchmark ($\beta_p$):
       $$\beta_p = \sum w_i \beta_i$$
